# Código Dragón - Taller de Fundamentos de Java

Proyecto desarrollado como parte del taller **Código Dragón** de la asignatura de **Programación**.

El objetivo del proyecto es practicar los fundamentos del lenguaje Java mediante una serie de ejercicios progresivos relacionados con un mundo de fantasía, trabajando conceptos básicos de programación antes de abordar un proyecto más complejo.

---

## Temas trabajados

Durante el desarrollo del taller se aplican conceptos como:

- Variables y tipos de datos.
- Entrada de datos con `Scanner`.
- Operadores aritméticos y lógicos.
- Estructuras condicionales (`if`, `switch`).
- Ciclos (`while`, `do-while` y `for`).
- Arreglos (Arrays).
- Clases y objetos.
- Validación básica de datos.
- Resolución y análisis de errores comunes en Java.
